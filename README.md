# SwapSphere – Campus Swap & Sell Marketplace

A responsive web app where students can swap or sell books, gadgets, furniture and more with others on campus.

## Features
- Browse items by category (Books, Electronics, Furniture, Clothing, Stationery, Sports)
- Search and filter by category and swap/sell type
- Save favourite items to a wishlist
- Post your own item using a validated listing form
- "Contact owner" pop-up that prepares an email or WhatsApp message
- Fully responsive layout with a mobile menu

## Tech Stack
HTML5, CSS3, JavaScript (ES6+)

## Run Locally
```
git clone https://github.com/kavaliushasree16-wq/SwapSphere.git
```
Open `index.html` in your browser. No installation needed.
